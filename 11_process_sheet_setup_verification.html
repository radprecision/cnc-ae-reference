📋 Process Sheet & Setup Verification

CNC AE Reference Library — Module 19 · Field standard · Mill setup · Lathe setup · Ownership and sign-off

Process sheet = how a part gets made. Setup verification sheet = proof the setup was correct before the first part was cut.These are two separate documents. The process sheet is authored by the AE. The setup verification sheet is filled out by the setup machinist and approved by the AE before first article.
Part number REQUIRED
Full part number with revision. Never leave rev blank — process sheets must match drawing rev exactly.
Revision REQUIRED
Must match drawing revision. A process sheet written to Rev A cannot be used for Rev B without update and sign-off.
Material specification REQUIRED
Full alloy, temper, condition — e.g. 6061-T6, 4140 Q&T 28-32 HRC. "Aluminum" is not a specification.
Zero point description MOST CRITICAL FIELD
Unambiguous description of G54 origin — readable by any machinist without the programmer present. "Corner of part" is insufficient. See Zero Point Descriptions tab.
Operation sequence
Numbered list of operations in sequence. Each operation = one setup. Operations reference the datum established in the previous operation.
Workholding description
Fixture ID or vise jaw type. Clamp torque in ft-lbs or N·m — not "tighten firmly." Soft jaw bore diameter if applicable.
Tool list reference
Tool list document number and revision. Tool list is a separate controlled document — do not copy tools into process sheet.
Program number and revision
NC program ID and revision. If the program changes, the process sheet must be updated and re-signed.
Quality checkpoints
In-process inspection dimensions with frequency. First article, first of every lot, every Nth part. Which features are CMM vs in-process gauge.
Coolant specification
Type, concentration, delivery method (flood, TSC, air blast). Especially important for aluminum (flood or air) vs titanium (TSC high pressure).
Stock size / billet dimensions
Raw material dimensions. Identifies any operations that depend on stock size (facing to thickness, for example).
Record retention
Inspection records must be retained per customer requirements. Aerospace/defense: 10 years minimum. Note retention requirement on process sheet header.
Mill setup verification — sequence mattersEach step builds on the previous. A failed step means stop and fix — do not proceed to the next step. The goal is to prove the setup is correct before any cutting begins.
1
Verify machine warm-up
Allow 30–60 minutes of spindle warm at production speed before precision work. Log start time. Spindle grows 0.001–0.003″ in Z during thermal stabilization.
2
Verify fixture / vise tram
Indicate vise jaw or fixture body. Maximum deviation: ±0.0005″ over 12″ for precision work, ±0.001″ for standard. Document result. If out of tram — stop, correct, re-indicate.
3
Load and clean fixture
Air blast all datum pads before loading part. Load part per workholding instructions. Torque all clamps per process sheet specification. Check part is fully seated with Mylar shim or indicator.
4
Set and verify work zero (G54)
Set G54 origin per process sheet zero point description. Verify by touching off the known reference surface with the probe or tool. Log actual vs expected values. Maximum allowed deviation before correction: ±0.002″ for standard, ±0.0005″ for precision.
5
Set and verify all tool length offsets
Set tool length for every tool in the program. Touch off against the same reference surface used for Z-zero. Verify each tool length by probing a known feature. Document all tool lengths in the setup sheet.
6
Dry run verification
Run the program in single block, feed hold at Z clearance, with spindle off. Verify all tool paths are over the correct features. Check rapid moves for clearance. Verify no tools move into clamps or fixture.
7
First article — measure and document
Machine first part. Measure ALL dimensions on the process sheet quality checkpoints. Document all measurements. Sign the setup verification sheet. AE reviews and approves before production begins.
TNR (Tool Nose Radius) is the most commonly wrong lathe offsetTNR compensation (G41/G42) requires the correct nose radius value in the offset register. A wrong TNR causes dimensional error on tapers and radii even when the straight diameter is correct. Verify TNR against the physical insert for every tool at setup.
1
Verify chuck / collet condition
Check chuck jaw runout — indicate OD of test bar. TIR must be within spec: 3-jaw chuck standard ≤0.005″, precision soft jaws ≤0.001″. Clean jaw contact faces. Verify jaw torque on collet nuts.
2
Load and indicate part
Load part in chuck or collet. Indicate OD for roundness and TIR. For 4-jaw chuck: adjust until TIR ≤ specified. For precision collet: verify TIR is within collet spec. Document TIR value.
3
Set work Z-zero
Face the part and set Z-zero at the faced surface. Or touch off known datum. Document Z-zero register value. Verify by touching off with the probe or reference tool.
4
Set X-zero (diameter mode)
Set X-zero at part centerline via tool touch-off on a known OD. Or use the tool setter. Verify: face to 0.005″ depth and measure face diameter — should match program expectation.
5
Set all tool offsets — including TNR CRITICAL
For each tool: set X and Z geometry offsets. Set TNR (tool nose radius) — verify against physical insert. Set tool nose orientation (imaginary tool tip direction: 1–9). Wrong TNR = wrong dimension on tapers/radii. Document all values.
6
Single-block dry run
Run in single block. Verify all tools approach from the correct direction. Check that no tool crashes into the chuck, collet, or tailstock. Verify rapid moves have adequate Z clearance.
7
First article — measure all features
Machine first part. Measure all dimensions including diameters, lengths, tapers, thread pitch diameters, and surface finish. Pay particular attention to any feature machined with TNR compensation. Document and sign.

If the process changes — restart the approval chainA program edit, fixture modification, or tooling change triggers a new first article and a new setup verification sheet sign-off. Changes made verbally or without documentation are an audit failure and a liability risk. This is not bureaucracy — it is traceability.
Zero point description is the most important field on the process sheetA vague zero point description requires the programmer to be present at every setup — or introduces errors when the programmer is not available. The description must be readable by any machinist without additional context.
QualityDescriptionAssessment
Poor"Corner of part"Which corner? Which face? In which orientation?
Poor"Front left corner, top face"What defines "front"? How is the part oriented in the vise?
Good"G54 X: left face of part (face touching fixed jaw). G54 Y: front edge of part (face facing operator). G54 Z: top face of part (face facing up, this operation). Part seated on parallels."Any machinist can set this up correctly without the programmer.
Excellent"G54 X: left face of part — touch off with 0.000 tool offset on the -X face per Op 10 datum. G54 Y: front face of part — touch off on -Y face. G54 Z: top face of part — face to blue ink and touch off. Parallels: 1-2-3 blocks, part elevated 1.000″ above vise jaws. Fixed jaw toward machine column."Complete and unambiguous. Could set up correctly on first read with no prior knowledge of the part.
Rule: if the programmer leaves the shop, any experienced CNC machinist should be able to set up the operation correctly using only the process sheet.If that's not true — the zero point description is insufficient.
DFM findings belong on the process sheetWritten DFM findings outperform verbal ones every time. A numbered list in the process sheet or a separate DFM findings document creates a paper trail, gives the customer something to share with their engineer, and establishes due diligence.
