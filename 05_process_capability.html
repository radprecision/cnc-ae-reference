CNC AE Reference Library — Module 20 · Cp/Cpk · Pp/Ppk · 5-piece pre-PPAP practice

The core questionHow does the natural spread of the process (6σ) compare to the tolerance band (USL−LSL)? If the process spread fits inside the tolerance with room to spare — the process is capable.

Cp — Potential

If the process were perfectly centered, how capable would it be? Measures spread vs tolerance. Does NOT account for centering.

Cpk — Actual

Given where the process is actually centered right now, how capable is it? Always ≤ Cp. The gap between Cp and Cpk reveals the centering problem.

Pp — Long-term potential

Same as Cp but uses overall std dev s — includes ALL sources of variation (drift, batch effects, shift changes).

Ppk — Long-term actual

What the process actually delivered to the customer. The PPAP number. Always ≤ Cpk because s ≥ σ̂.

Capability indices assume a stable, normal processCalculate Cpk only after verifying statistical control (control chart). Non-normal data requires different methods. Never exclude data points to improve the indices.

Cp and Cpk (short-term σ̂)

Cp = (USL − LSL) / (6 × σ̂) CPU = (USL − x̄) / (3 × σ̂) CPL = (x̄ − LSL) / (3 × σ̂) Cpk = min(CPU, CPL) σ̂ = R̄/d₂ or s̄/c₄ (within-subgroup sigma from control chart)

Pp and Ppk (overall s)

Pp = (USL − LSL) / (6 × s) PPU = (USL − x̄) / (3 × s) PPL = (x̄ − LSL) / (3 × s) Ppk = min(PPU, PPL) s = √[Σ(xᵢ − x̄)² / (n−1)] (overall standard deviation of all data)

Cpk can never exceed CpIf calculated Cpk > Cp — there is a calculation error. A process with Cp < 1.33 cannot achieve Cpk = 1.33 regardless of centering.

Cp/Cpk — short-term capability

Uses within-subgroup σ̂. Excludes between-subgroup variation. Represents what the process CAN do under ideal conditions. The process's potential.

Pp/Ppk — long-term performance

Uses overall s. Includes everything — drift, batch effects, operator changes. Represents what the process ACTUALLY delivered. The PPAP number.

Why PPAP asks for bothIf Cpk ≈ Ppk: process is stable. If Cpk >> Ppk: significant between-subgroup variation exists. A Cpk of 1.67 with Ppk of 0.95 is a warning sign, not a success.

Automotive OEM practice — 5-piece pre-PPAP checkRun 5 consecutive parts before committing to a full 30-piece PPAP study. Identifies gross process problems early. A passing 5-piece check does NOT replace PPAP — it confirms the process is ready to attempt it.
GateCriterionWhy
Gate 1All 5 pieces in specificationFundamental — if any piece fails, the process is not ready
Gate 2Range ≤ 50% of toleranceSpread check — if range already uses 50% of tolerance band, Cpk will likely fail with more data
Gate 3Mean within ±25% of tolerance from nominalCentering check — off-center process will fail even if spread is adequate
Gate 4Indicative Cpk ≥ 1.00Preliminary capability — not statistically reliable with n=5, but catches obvious failures
The 5-piece Cpk is indicative onlyn=5 is too small for a statistically reliable capability determination. Do not submit a 5-piece Cpk for PPAP. All four gates must pass before proceeding to the 30-piece study. A failing gate means fix the process first — do not proceed to PPAP.
