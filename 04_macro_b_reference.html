⚠ NULL ≠ ZERO — The #1 macro debugging conceptA variable that has never been assigned is NULL (#0) — not zero. #1 EQ #0 tests for null. #1 EQ 0 tests for the number zero. These are completely different tests. A null variable in an axis word silently omits that axis from the block. A zero moves the machine to position 0.

Four building blocks

Variables — storage (#100, #500, etc.)
Arithmetic — calculation (#100 = #1 + #2)
Control flow — IF/GOTO, WHILE/DO
System variables — machine state (#5021, #5221)

Why macros exist at AE level

1. Parametric families — one program drives a part family
2. Automated probing — measure, calculate, adjust offset
3. Custom cycles — bolt circles, patterns, thread mill loops

Brackets vs parenthesesSquare brackets [ ] are for math. Parentheses ( ) are for comments and are ignored by the controller. Writing (SIN(45)) means the entire thing is a comment. SIN[45] is the correct trig call.

NEVER write to #5201#5201 is the external work offset — writing to it shifts ALL work coordinate systems simultaneously. Write to the specific register: #5221 for G54 X, #5222 for G54 Y, #5223 for G54 Z.
Standard probing value: #3004 = 3Disables both feed hold and FRO during G31 probe move. Restore #3004 before #3003. Restore both before EVERY exit from the macro including alarm branches.

Write to #5221 not #5201#5201 shifts ALL fixtures. #5221 is G54 X only. This is the most dangerous probing mistake.
Core concepts (variables, arithmetic, IF/GOTO, WHILE/DO) are identical across Fanuc, Haas, and Okuma. Variable numbers and system variable addresses differ significantly — code is not portable without modification.

Haas NGC critical differenceHaas NGC uses #10000–#10999 for permanent common variables (NOT #500–#999 like Fanuc). Old macros written for legacy Haas will read incorrect values on NGC machines. Always verify which controller generation is installed.
